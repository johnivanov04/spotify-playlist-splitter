# Screenshots

The root README references the following files. Capture them at roughly
1400–1600px wide and save them here with these exact names:

| File | What to capture |
|---|---|
| `landing.png` | The logged-out landing page — title, tagline, and the four numbered steps. |
| `vibes.png` | A loaded playlist showing the generated groupings with their names, descriptions, and track counts. |
| `track-selection.png` | One grouping expanded — per-track checkboxes, Select all / Deselect all, and the create button. |

Optional but worth adding:

| File | What to capture |
|---|---|
| `steer.png` | The steer input with a prompt typed in, or the quota banner. |
| `demo.gif` | 10–20s: pick a playlist → groupings load → expand one → create it → the result in Spotify. |

Your Spotify display name and playlist artwork will be visible in most of
these; blur them if you'd rather not have them public.
